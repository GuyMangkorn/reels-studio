## Category pick before pitching

**Default (user, 17 Nov 2026).** Every edu [ideation round](../../docs/delivery-workflow.md#ideation) starts with a category pick, unless the user's prompt already names a category or a concept.

1. The coordinator shows the table below in the reply, with Preaw's ER11 note per row, then asks with the structured-question tool. The tool takes at most four options: offer the four categories with the best ER11 fit that the latest rounds have not used, the first marked recommended; "Other" takes any ID from the table or a new category.
2. The pick (one or more IDs, the user's words, date) goes in the series `delivery.md` with the round ID.
3. Preaw pitches the round's concepts only inside the picked categories and names the ID in each concept file and in the [concepts index](../../scripts/edu-series/concepts/index.md) row's title cell suffix, e.g. `… (CAT05)`.
