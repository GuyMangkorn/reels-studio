# Glossary

## Video production

**Project**:
A story and its selected deliverables. A project can contain a Reels deliverable and a separate YouTube Long deliverable.

**Deliverable**:
An independently edited version of a story, such as Reels or YouTube Long; changing the frame shape alone does not create a second editorial version.

**Shared character**:
A character identity reused across projects. Projects using it receive changes to that shared identity on their next render.
