# Scripts

Shared tools any role may run. Check here before writing a one-off command. A procedure that agents repeat becomes a script under the [tooling rule](../docs/contributing.md#tools-and-document-improvements). Episode-only scripts stay in `scripts/<episode>/` or the asset folder, and are listed in that episode's `build-notes.md`.

| Script | Does | Run |
| --- | --- | --- |
| `setup.sh` | Prepares a checkout after a clone, a folder move or a new machine (safe to re-run): `npm ci` when needed, the three local venvs (`.venv-whisper`, `out/gemini-venv`, `out/voice-venv`) rebuilt only when they do not run, `store.py fetch` + `verify`, and `--repair-worktrees` | `bash scripts/setup.sh [--no-venvs] [--repair-worktrees]` |
| `render.mjs` | Renders compositions, stills or frame lists into `out/<CompositionId>/`; parallel-safe. A delivery render of `<ID>` also renders `<ID>-COVERS` stills into `out/<ID>/covers/` ([cover principles](../docs/cover-principles.md)); `--covers` renders only those. Renders only the registry's selected ending unless `--endings` is given, then normalizes loudness in place. Painted/WebGL episodes: `--gl=angle --timeout=180000` (per-frame ms) so a slow frame does not stall; `--concurrency` defaults to 4 | `npm run render -- <CompositionId> [--stills] [--frames=90,210] [--endings=A_fade,B_loop] [--gl=angle] [--timeout=180000] [--concurrency=4]` Scene cache: renders per scene into `$REELS_STORE/cache/segments/` and reuses unchanged scenes (`segments.mjs`; `--no-cache` to disable); `--preview` half-size quick look; `--draft` blocking draft (flat washes, no hatching; full size, cached, `out/<ID>/draft/`); `--range=a-b` renders the touched scenes into the cache, then cuts the range; pinned finals stop a render that would change them (`--keep-pinned` / `--repaint=<shot,...|all>`). |
| `paint-bench.mjs` | Painted-frame benchmark: stills through one Chrome (`--gl=angle`) with the BrushCanvas `paintProfile` prop; per-frame scene JS, brush calls by name, layers, `render()`, GPU wait, still wall time, plus PNGs ([DF-20261031-paint-seed-defer](../docs/dev-findings/DF-20261031-paint-seed-defer.md)) | `node scripts/paint-bench.mjs <ID> out/bench/<name> [--every=30 \| --frames=a,b] [--props=<json>] [--no-profile]` |
| `paint-bench-compare.mjs` | Compares two paint-bench runs: changed channels, max difference, PSNR per frame (judge against an A/A pair), mean stage timings | `node scripts/paint-bench-compare.mjs <beforeDir> <afterDir> [--list]` |
| `stills.mjs` | `renderStills({frames, outputFor, puppeteerInstance, ...})` renders a frame list as PNGs in evenly spaced `renderFrames` runs on long-lived pages (12 ZCPAINT stills 10.2 s → 3.5 s vs `renderStill` per frame); used by `render.mjs --stills`. As a CLI it renders `ID FRAME OUTPUT` lines from stdin with one Chrome (`--gl=angle`); the sheet `.sh` scripts pipe their frame lists into it instead of `npx remotion still` per frame. Pass the browser as `puppeteerInstance`, never `browserInstance` (ignored by Remotion: a new Chrome per call) | `printf 'ID 0 out/x.png\n' \| node scripts/stills.mjs <bundleDir\|entry.ts> [--props=<json>]` |
| `reference-frames.py` | Reference stills of a composition (PNG every 5 s at the current commit, `--gl=angle`) into the asset store (`projects/<PROJECT>/reference/<ID>/<commit>/`) with SHA-256, PSNR against the delivered MP4 (`--mp4 ID=path`) and a byte-identical count against the previous set | `python3 -I scripts/reference-frames.py <ID> [--mp4 <ID>=<mp4>]` |
| `narration.py` | Local Edge TTS narration (default Niwat +5%; female: `--voice th-TH-PremwadeeNeural`; `--rate`) plus the committed 30 fps RMS envelope | `npm run narration -- …` |
| `voice-preset.py` | One Thai line in a character register (child, elderly, alternate adult) from Edge TTS + ffmpeg; child/elderly via Praat/WORLD in the `out/voice-venv` venv ([voice-tuning skill](../.agents/skills/voice-tuning/SKILL.md)) | `out/voice-venv/bin/python -I scripts/voice-preset.py --preset child-girl --text "…" out.wav` |
| `gemini-tts.py` | Thai line with emotion/style and inline tags, voice listing and voice design from Gemini TTS, in the `out/gemini-venv` venv ([gemini-tts skill](../.agents/skills/gemini-tts/SKILL.md)). One attempt per call, no retries: quota/429 exits 3, `--timeout` (default 180 s) exits 4 | `out/gemini-venv/bin/python -I scripts/gemini-tts.py say --voice Kore --style "sad, slow" --text "…" out.wav` |
| `narration_files.py` | Narration from supplied per-beat audio files (e.g. Botnoi) plus the envelope | `python3 scripts/narration_files.py …` |
| `narration/align-full.py`, `cut-gaps.py`, `voice-match.py`, `assemble-narration.py` | Split one continuous TTS read (e.g. Gemini, which has no word timings) into beats: Whisper alignment to the script, cuts at real energy gaps, tail-variation voice match, slot-plan assembly. Local only (no API calls); explicit path arguments, see each docstring | `"<main>/.venv-whisper/bin/python" -I scripts/narration/align-full.py --help` |
| `transcribe.py` | Thai speech to text (faster-whisper), for intake or caption QA | `python3 scripts/transcribe.py …` |
| `loudness.mjs` | Two-pass loudnorm on a finished MP4 (≈ −14 LUFS, ≤ −1 dBTP), video copied | `node scripts/loudness.mjs …` |
| `qa-sheet.sh` | Downscales and tiles frames into one PNG for an agent to view ([CB03](../AGENTS.md#context-budget)) | `scripts/qa-sheet.sh out.png [--cols 4] [--width 270] f1.png f2.png …` |
| `ep.py` | Episode record edits: tick a `task.md` step, set its Now/Next line, read or set a Markdown table cell (`delivery.md` Stage, scene-sheet columns), list/get/set `review-rows.json` shots, beats, looks and top-level keys; each edit must match once ([task file](../docs/delivery-workflow.md#task-file)) | `python3 -I scripts/ep.py tick scripts/<ep>/task.md W5.3`; `… cell scripts/<ep>/delivery.md <ID> "Stage / Next owner" "…"`; `… rows <review-rows.json> set <shot> end=72` |
| `viewer-check.py` | Builds the [viewer check](../docs/sequence-workflow.md#viewer-check) input as one `bundle.md` plus shot sheets, skipping shots unchanged since a recorded pass | `python3 -I scripts/viewer-check.py bundle <review-rows.json> --stage draft`; then `… record <review-rows.json> --stage draft <verdicts.json>` |
| `caption-breaks.mjs` | Thai caption line breaks: authored breaks that split a word, cues over 2 lines, lines likely to wrap ([editor step 5](../docs/editor-workflow.md#steps-and-completion-criteria)) | `node scripts/caption-breaks.mjs <cue JSON> [--max 26]` |
| `caption-zone.py` | Caption band background brightness per frame, plus an overlay of the caption-safe box and band ([caption safe zone](../docs/production-requirements.md#vertical-caption-safe-zone)) | `python3 -I scripts/caption-zone.py [--band 860:1248] [--overlay-dir DIR] [--shade-centre Y] f1.png …` (`--shade-centre` also measures the caption ink centre against the shade centre) |
| `zombie-condo-paint/label-sheet.py` | Labelled review sheet: frames at a fixed width, each with its label lines (shot ID, clocks, plate frame), rendered by headless Chrome ([preview labels](../docs/boss-asset-workflow.md#preview-labels)) | `python3 -I scripts/zombie-condo-paint/label-sheet.py MANIFEST.tsv OUT.png [--cols 3] [--width 540] [--title TEXT]` |
| `zombie-condo-paint/place-narration.py` | ZCPAINT Editor: Edge TTS per VO line (`short/vo-<LANG>.json`), each onset pinned to its anchor, overlap check, loudness to the export target, `ZCPAINT-SHORT-<LANG>.lines.json` and the 30 fps envelope | `python3 -I scripts/zombie-condo-paint/place-narration.py --lang TH --total 71.2 --write` |
| `zombie-condo-paint/measure-sfx.py` | Sound candidate measurement for cue selection (peak, RMS, onset, tail, dB envelope); agents cannot listen, so a measured pick is not an audio approval | `python3 -I scripts/zombie-condo-paint/measure-sfx.py FILE.wav ...` |
| `zombie-condo-paint/copy-sounds.sh` | Copies the shared-library IDs used by ZCPAINT-SHORT into `public/sfx` and `public/audio`, adds the NOTICE block (idempotent) | `bash scripts/zombie-condo-paint/copy-sounds.sh` |
| `zombie-condo-paint/editor-stills.sh` | ZCPAINT Editor stills from the real registry (`--gl=angle`), per-ID output under `out/samples/`, TSV manifest | `sh scripts/zombie-condo-paint/editor-stills.sh REVISION ZCPAINT-SHORT-TH B01:45,B02:180` |
| `zombie-condo-paint/render-chunks.sh` | ZCPAINT-SHORT MP4 in frame chunks (fresh bundle, `--gl=angle`, progress under `out/logs/`), joined, then `loudness.mjs` in place and an ffprobe check; resumable per chunk | `sh scripts/zombie-condo-paint/render-chunks.sh ZCPAINT-SHORT-TH 534` |
| `shot-projection.py` | Projects scene-sheet anchors through the shot camera to pixels: lead height, screen side, caption-band overlap ([Film pre-handoff checks](../docs/mark-storyboard-workflow.md#pre-handoff-checks)) | `python3 -I scripts/shot-projection.py shot.json [--min-height 480]` |
| `storyboard-page/build.py` | User storyboard review page, one per deliverable: Film's `review-rows.json` into the fixed template plus downscaled previews and shot clips, with per-shot stages storyboard → draft → final → pinned, ready to publish ([review page](../docs/mark-storyboard-workflow.md#user-storyboard-review-page)) | `python3 -I scripts/storyboard-page/build.py storyboards/<ep>/short/review-rows.json` |
| `storyboard-page/clips.mjs` | Review clips per shot: renders each shot ±1 s through the scene cache (`--draft` for the blocking draft; `--full` renders the whole final cut once for the Final tab) and writes a 360×640 proxy plus `clip`, `clipIn`, `clipOut` and `stage` into the review rows ([proposal](../docs/reviews/2026-11-01-shot-by-shot-workflow-proposal.md)) | `node scripts/storyboard-page/clips.mjs <ID> <review-rows.json> --shots=a,b \| --stage=draft [--draft] --gl=angle` |
| `pin.mjs` | Pins approved finals in the scene cache (`pins.json` beside the segments); a later render that would change a pinned scene stops until `--keep-pinned` or `--repaint` | `node scripts/pin.mjs <ID> pin <shot> <from>-<to>` · `pin-rows <review-rows.json> [--shots=a,b]` · `unpin <shot\|all>` · `list` |
| `check-links.py` | Relative Markdown links and `#anchors`; changed files by default | `python3 -I scripts/check-links.py [--all \| FILE.md …]` |
| `context-map.py` | Checks [docs/context-map.md](../docs/context-map.md): dead links or anchors, and modules no entry mentions; lists `Pending` paths that have landed. Run by `npm test` | `python3 -I scripts/context-map.py` |
| `sound-library.py` | Shared sound library in `$REELS_STORE/library/sound`: search sidecars, file a processed sound (copy + `library` block + INDEX row), check INDEX drift | `python3 -I scripts/sound-library.py search zombie` |
| `store.py` | Asset store `$REELS_STORE` (default `~/ReelsStore`; [proposal](../docs/reviews/2026-10-31-asset-store-proposal.md)): `archive` renders (`out/<ID>/` → `projects/<PROJECT>/renders/<ID>/<commit>/`, run by `render.mjs`) or other output (`--path DIR --project P --kind K`), `--all-worktrees` sweeps every worktree; `put` a file (immutable media, sha256 manifest); `use`/`adopt` media for an episode (`src/videos/<ep>/assets.lock.json` + `public/` copy); `fetch` the gitignored `public/` media back; `import` a folder; `backfill-chat` user-attached images; `prune` gitignored folders (drops copies already stored and scratch; dry run unless `--delete`); `verify` hashes | `python3 -I scripts/store.py fetch [episode...]` |
| `painted-kit/store-page.py` | Kit browse page `$REELS_STORE/index.html`: renders cast cards, people sheets, poses and the KIT-MOTIONS reel, files them under `library/kit-page/<date>-<hash>/` and writes the page (casting-line builder, pose and motion lists); rerun after a kit change | `python3 -I scripts/painted-kit/store-page.py [--skip-render]` |
| `painted-kit/plates.ts` | Plate gallery (`src/painted/kit/plates.ts`): renders each `PLATES` entry missing from the store as a clean plate (no captions), files it at `projects/KIT/plates/<id>.png`, prints a suggested palette, and draws the `KIT-PLATES` sheet in `out/kit-plates/`. `--sheet-only` redraws the sheet from the store, `--only=<ids>`, `--no-store` |
| `episode-media.ts` | Lists the `public/` media each video's timelines reference (`<episode>\t<path>` lines) | `node --import tsx scripts/episode-media.ts [episode...]` |
| `codex-run.sh` | Offloads a task to Codex (`codex exec`, default `gpt-6.1-terra` / high, read-only unless `--write`); prints only the final message, full log under `out/logs/`; exit 75 on Codex usage limit, and the caller then does the task itself | `scripts/codex-run.sh [--write] "PROMPT"` |
| `usage-report.py` | Token usage of this project's Claude Code sessions and role agents ([CB05](../AGENTS.md#context-budget)); `--by-model` adds API dollars per role, model and effort, `--rework` repeat runs per role and branch | `python3 -I scripts/usage-report.py [--since YYYY-MM-DD] [--by-model] [--rework]` |
| `hooks/agent-run-log.py` | PreToolUse hook (`.claude/settings.json`): logs each role agent's starting model and effort to `out/logs/agent-runs.jsonl` in the main checkout, for `usage-report.py --by-model` | Runs automatically in Claude Code sessions |
| `git-hooks/post-checkout` | Moves every new `git worktree add` onto freshly fetched `origin/main` (only when the start point has no commits of its own) | Install once per clone: `ln -s ../../scripts/git-hooks/post-checkout .git/hooks/post-checkout` |

Each script's header comment is its full usage.
