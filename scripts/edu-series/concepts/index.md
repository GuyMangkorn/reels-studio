# EDU concepts — index

One row per concept the channel has made. Each concept has its own file `C<nn>.md` (ID `C<n>`, file number zero-padded). Read this index first, then only the concept file you need ([CB01](../../../AGENTS.md#context-budget)).

**Reset (user, 2026-11-13):** every unmade concept (C13, C25, C31, C33–C36, C38, C40–C42, C44–C60) was deleted completely, text and titles, along with the unpublished episodes. The old single `concepts.md` is in Git at commit 8cf02ff.

## How a new round is filed

1. Preaw writes one file per concept, `C61.md` onward (next free ID: **C61**), with the pitch and the [ER08](../../../channels/edu/script.md) pitch check, and adds a row here with status `pitched` and the round ID (`R11`, ...).
2. Film adds a `## Film annotation (W0.2)` section to each concept file of the round.
3. After the user picks, the coordinator sets each row: `picked` (with the episode ID), `dropped`, or leaves `pitched`. Write the round's pick note (user's words, date) in `../delivery.md`.
4. When the episode is published, set the row to `made`.
