## Wording fixes and hedges for Preaw

1. **Hook** "ถ้าวันหนึ่งคุณได้ยินเสียงจากต่างดาว…": fine, it is a "ถ้า". Optional: no change.
2. **Beat 2** (`must-fix` if the picture or line implies a nearby star): "ไปกลับก็หมดชีวิตคุณแล้ว" is wrong for Proxima (about 8.5 yr). Use a star "หลายสิบปีแสง" away (about 40+ ly gives 80+ yr), or soften to "ไปกลับเป็นสิบ ๆ ปี". Film's on-screen star must match.
3. **Premise tension** (optional but note): a signal arriving means somebody transmitted, which sits oddly beside "everyone stays silent". The payoff line explains it only if the sender is naive or the signal is a bait/test. Preaw should decide whether this is intended; it can be a good ER03 flip or a plot hole a viewer will raise.
4. **Beat 4** "คนที่อ่อนกว่า อาจกลายเป็นคนที่แข็งกว่า": it is a model step, keep "อาจ". Do not state that civilizations grow explosively as a fact.
5. **Payoff** "ป่าที่ไม่มีใครเลย กับป่าที่ทุกคนกลั้นหายใจ… ฟังดูเหมือนกัน": acceptable as logic; keep "ถ้า" or "อาจ", not "ท้องฟ้ามีอารยธรรมเต็มไปหมด".
6. Do not say "ทฤษฎี" as if proven; "แนวคิด" or "การทดลองในความคิด" is safer. Do not present it as the answer to Fermi; add "นี่เป็นแค่คำตอบหนึ่งในหลายคำตอบ" if there is time (ER10 narrow hedge, within the 10 s answer cap ER09).
7. Do not quote Fermi verbatim with a day; if shown, paraphrase.
8. Do not state a Thai book title or publisher in the video; there is no inspected source.
9. Sound (per sound workflow): the signal ping is fictional; label it as a dramatization if text implies a real detection ("ภาพจำลอง"). The "Wow! signal" (1977) is real, but nothing here uses it; do not reference it as if it were this ping.
