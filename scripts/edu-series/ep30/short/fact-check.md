### FC02 — L14 placement (open question 4) — optional

- Evidence: SRC009 (anonymous page, lead only) dates the remark to *Western Mail* 10 Nov 1932; Wikipedia cites a 1953 retrospective. Date and venue unverified in both directions.
- Verdict: the line itself says only "แมเจอร์เองยังพูดเลยว่า", no date or venue, so it implies nothing false. - Optional hedge against the 1953 possibility: keep the line undated on screen and in captions (script already forbids a venue or date card). Do not add "ตอนนั้น" or "หลังถอนทัพ". No change needed.

### FC03 — premise framing of "ต้องถอนทัพ" and "ถอนอีก" — optional

- Evidence: SRC001 re-read: the 8 Nov withdrawal followed negative press coverage (including claims few emus had died), and the second end was Meredith's recall on 10 Dec. Meredith's report called the second phase more productive; later view is minimal effect on emu numbers. No source says the soldiers were beaten in battle.
- Finding: L01 "แล้วต้องถอนทัพ" and L13's silent cause let the viewer infer "withdrawn because the birds won". True in outline (the operation failed and was ended) but the first withdrawal's stated trigger was press criticism. The on-screen label and the comic frame cover this; no false statement.
- Optional replacement for L13 if Preaw wants the cause in, same bold energy: "ผ่านไปหกวัน ข่าวลงหนังสือพิมพ์ยับ รัฐมนตรีสั่งถอนทัพ… รอบที่หนึ่ง" (about +1.0 s; see FC06, so only with a cut). ### FC04 — L17 "1912" and the 1908 arms (open question 5) — optional

- Evidence: SRC010 re-read: the **1908** arms (Edward VII, 7 May 1908) already had the kangaroo and emu supporters; the current arms (George V, 19 Sep 1912) kept both supporters, dropped the grass bed, changed the scroll and added the state badges.
- Verdict: **"อยู่บนตราแผ่นดินออสเตรเลียมาตั้งแต่ปี 1912" is true but understated.** The emu has been on Australia's arms since 1908, not first in 1912. It does not mislead the takeaway (it is 20 years before 1932 either way, and the line does not say 1912 was the first appearance), but "มาตั้งแต่ปี 1912" reads as "since the arms were created" to a casual viewer, and a viewer who checks will find 1908.
- Recommended replacement (both true, same punch, no ER09 impact, digits caption "1908"): **"ส่วนนกอีมู อยู่บนตราแผ่นดินออสเตรเลียมาตั้งแต่ปี 1908"**. 1908 is the earliest documented supporter grant per the tertiary source; the 1912 arms are the current ones. Alternative that avoids picking a year: "ส่วนนกอีมู อยู่บนตราแผ่นดินออสเตรเลียมาก่อนสงครามนี้ยี่สิบกว่าปี" (1932 minus 1908 = 24, minus 1912 = 20; both "ยี่สิบกว่า" holds only for 1908; use "สองทศวรรษ" if 1912 stays). Confidence: tertiary only; open the APH page or the Governor-General royal-warrant record before locking. Note the Film brief says "emu (and kangaroo) supporter" which is fine for both versions; if the 1908 date is used, Film must not paint the 1912 state-badge shield as "the 1908 arms"; showing the current arms with the line is fine because L18 says "วันนี้ก็ยังอยู่".
- Severity: optional. If kept as 1912, no false statement.
