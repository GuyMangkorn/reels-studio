## Long U01 — เราเลือกคำอธิบายเร็วไปไหม? (0–45s)

### CATBOX-C06-U01-B01 · 0–10s

**VO:** “แมวเลือกกล่อง หรือเราเลือกคำตอบเร็วไป? เจ้าของเปิดแฟ้มใหม่ คราวนี้ไม่ตั้งชื่อว่า เหตุผลที่แมวต้องลงกล่อง แต่ตั้งว่า เรารู้อะไรจากหลักฐานชุดนี้บ้าง”

**ซับ:** “เราเลือกคำตอบเร็วไปไหม?” / “หลักฐานชุดนี้บอกอะไรได้บ้าง?”

**เหตุการณ์:** นำCL03สองกองแฟ้มที่ปลูกแล้วกลับมา ไม่เพิ่มเครื่องทดลองหรือกฎเฉลยใหม่

### CATBOX-C06-U01-B02 · 10–23s

**VO:** “กองแรก สิ่งที่สังเกตหรือวัดได้ แมวบางตัวเลือกเข้าไปอยู่ในกรอบ และงานศูนย์พักพิงพบว่าที่ซ่อนช่วยให้คะแนนความเครียดลดเร็วในบริบทที่ศึกษา สองเรื่องนี้จริงตามขอบเขต แต่ยังไม่ใช่เหตุเดียวกัน”

**ซับ:** “สังเกต: บางตัวเลือกกรอบ” / “วัด: ผลของที่ซ่อนในบริบทที่ศึกษา” / “ยังใช้แทนเหตุเดียวกันไม่ได้”

**ข้อความภาพ:** “ผลที่วัด / ตามบริบทการศึกษา” ไม่สรุปกองนี้เป็น “พิสูจน์กลไกแล้ว”

### CATBOX-C06-U01-B03 · 23–35s

**VO:** “กองถัดมา เหตุที่อาจเป็นไปได้ ความอุ่น ที่ซุ่มเล่น สัมผัสด้านข้าง ส่วนความใหม่อาจชวนให้เดินมาสำรวจ แต่ยังไม่ตอบครบว่าเลือกพักทำไม แต่ละข้อมีหลักฐานกับข้อจำกัดไม่เท่ากัน”

**ซับ:** “เหตุเสนอ: อุ่น / ซุ่ม / สัมผัสข้าง” / “ความใหม่: สำรวจ ≠ เลือกพัก” / “หลักฐานแต่ละข้อไม่เท่ากัน”

**ข้อความภาพ:** “สมมติฐาน / ยังไม่ยืนยันเหตุเฉพาะครั้ง”; สัมผัสข้างระบุ “หลักฐานอ่อน”; ไม่ใช้คำlikelyแบบมั่นใจเท่ากันทุกใบ

### CATBOX-C06-U01-B04 · 35–45s

**VO:** “ส่วน แมวทุกตัวต้องลง กับ จำอ้อมกอดแม่แน่นอน ยังเอามาเป็นข้อสรุปไม่ได้ เจ้าของไม่ทิ้งความเป็นไปได้ เขาแค่เลิกประทับคำว่า ยืนยันแล้ว ลงบนทุกใบ”

**ซับ:** “ทุกตัวต้องลง / จำแม่แน่นอน: ยังสรุปไม่ได้” / “เป็นไปได้ ≠ ยืนยันแล้ว”

**ข้อความภาพ:** “คำอ้างเกินหลักฐาน” คู่คำเหมารวมตั้งแต่ปรากฏ; ไม่ใช้mythเพื่อสื่อพิสูจน์ว่าเป็นไปไม่ได้

## Long U02 — ที่นั่งยังอ่านใจไม่ได้ (0–45s)

### CATBOX-C06-U02-B01 · 0–10s

**VO:** “นั่งในกรอบ แปลว่าคิดว่ามีกล่องจริงไหม? ยังยืนยันแบบนั้นไม่ได้ เราเห็นการเลือกพื้นที่ แต่ไม่ได้เข้าไปเห็นภาพในหัวแมว และกรอบแบนก็ยังไม่ใช่ที่หลบที่มีผนัง”

**ซับ:** “นั่งในกรอบ ≠ ยืนยันว่าคิดว่ามีกล่อง” / “กรอบแบนยังไม่ใช่ที่หลบจริง”

### CATBOX-C06-U02-B02 · 10–23s

**VO:** “จุดที่ทำให้คดีนี้เปลี่ยน คือคำถามเล็ก ๆ เราเห็นมันทำอะไร หรือเรากำลังเติมเหตุผลให้มัน? การพุ่งในเรื่องของโมจิ กับการเลือกในงานวิจัย ต่างต้องถูกเล่าตามสิ่งที่มันบอกได้จริง”

**ซับ:** “เห็นการกระทำ / หรือเติมเหตุผล?” / “เรื่องโมจิ ≠ ข้อมูลทดลอง”

**เหตุการณ์:** payoffCL04 ไม่เอาฟุตเทจเรื่องแต่งวางเป็นกราฟผลวิจัย

### CATBOX-C06-U02-B03 · 23–35s

**VO:** “พอเจ้าของเรียงคำอธิบายเสร็จ โมจิก็เดินผ่านแฟ้มทั้งหมด ไปนั่งในกล่องเก่าข้างโซฟา ใบที่อยู่ตรงนั้นมาตั้งแต่ต้น เขายิ้มแล้วถาม เอ้า แล้วใบนี้เลือกเพราะอะไรล่ะ?”

**ซับ:** “เรื่องสมมติ: โมจิเลือกกล่องเก่า” / “แล้วใบนี้ เลือกเพราะอะไร?”

**เหตุการณ์:** payoffCL01 เห็นว่าเป็นกล่องเดิม ไม่ใช้กล่องใหม่เข้ามาเป็นข้อมูลเด็ดขาด; ป้าย “เรื่องสมมติ / ไม่ใช่ผลทดลอง” ตลอดมุก

### CATBOX-C06-U02-B04 · 35–45s

**VO:** “เขามองช่องว่างหลังคำว่า เพราะ แล้วเขียนว่า ครั้งนี้ ยังไม่รู้ กล่องมีหลายหน้าที่ ส่วนเหตุที่เลือกใบนี้… ยังต้องถามต่อ”

**ซับ:** “กล่องมีหลายหน้าที่ / เหตุที่เลือกใบนี้ ยังไม่รู้”

**ท้าย:** payoffCL02; เสียงจบเป้าราว42sค้าง3sกับช่องคำตอบที่เจ้าของยอมเว้นไว้ ไม่มีเสียงพากย์แมวเฉลยว่าเพราะอุ่น/แม่กอด. A hold→fade; B hold→กลับคำถามเปิด โดยยังคงสถานะเรื่องแต่ง/สมมติฐาน ไม่อ้างloopผ่านQAแล้ว

## Short S01 — แมวเลือกกล่อง แต่เราเลือกคำตอบเร็วไปไหม? (45s)

### CATBOX-C06-S01-B01 · 0–8s

**VO:** “แมวเลือกกล่อง แต่เราเลือกคำตอบเร็วไปไหม? บางตัวเลือกแม้แต่กรอบแบน แต่ยังไม่ได้แปลว่ามันคิดว่ามีกล่องจริง”

**ซับ:** “เราเลือกคำตอบเร็วไปไหม?” / “เลือกกรอบ ≠ คิดว่ามีกล่องแน่นอน”

### CATBOX-C06-S01-B02 · 8–22s

**VO:** “งานเรื่องกรอบวัดการเลือก ส่วนงานที่ซ่อนในศูนย์พักพิงดูคะแนนความเครียด เราเอาผลสองแบบมาเรียกเป็นเหตุเดียวไม่ได้ กล่องจริงบังตัวได้ แต่กรอบบนพื้นไม่มีผนังแบบนั้น”

**ซับ:** “งานต่างกัน วัดคนละอย่าง” / “กล่องที่หลบได้ ต่างจากกรอบแบน”

### CATBOX-C06-S01-B03 · 22–34s

**VO:** “ความอุ่น การซุ่ม หรือสัมผัสด้านข้าง อาจมีส่วน แต่ยังเป็นเหตุเสนอที่หลักฐานไม่เท่ากัน และไม่ได้ยืนยันว่าแมวตัวนี้เลือกกล่องครั้งนี้เพราะอะไร”

**ซับ:** “เหตุเสนอมีหลักฐานไม่เท่ากัน” / “ยังไม่ยืนยันเหตุเฉพาะครั้ง”

**ข้อความภาพ:** “สมมติฐาน”; สัมผัสด้านข้าง “หลักฐานอ่อน” เช่นLong

### CATBOX-C06-S01-B04 · 34–45s

**VO:** “ในเรื่องสมมติ โมจิกลับกล่องเก่า เจ้าของเลยแก้ป้ายใหม่ กล่องมีหลายหน้าที่ แต่เหตุที่เลือกใบนี้ ยังไม่รู้”

**ซับ:** “เรื่องสมมติ ไม่ใช่ผลทดลอง” / “เหตุที่เลือกใบนี้ ยังไม่รู้”

**ท้าย:** เสียงจบเป้าราว42sค้าง3s; สำหรับShortต้องเห็นกล่องเก่าตั้งแต่B01เพื่อให้มุกกลับเดิมมีclueในตัวเอง ไม่อาศัยการดูLongมาก่อน. A/Bendingตามข้อตกลง ไม่ตัดก่อนประโยคยังไม่รู้
