## แกนเรื่องและ ending

Logline: เจ้าของเห็นแมวในกรอบที่ไม่มีกำแพง จึงเปิดแฟ้มสืบว่ากล่องมีพลังอะไร แต่คำตอบที่ฟังดูปิดคดีได้ทุกข้อกลับตอบคนละคำถาม สุดท้ายเขาจัดแฟ้มใหม่ตามระดับหลักฐาน ขณะที่โมจิกลับไปนั่งในกล่องเก่าที่อยู่ข้างโซฟามาตั้งแต่ต้น

เจ้าของต้องการคำตอบเดียวไว้ติดป้ายบนกล่อง อุปสรรคคือสิ่งที่เห็นเหมือนกัน—แมวเข้าไปอยู่ในพื้นที่หนึ่ง—อาจไม่ยืนยันเหตุผลเดียวกัน อารมณ์: สงสัย → สนุกกับการสืบ → เกือบหลงคำอธิบายสวย ๆ → ยิ้มเมื่อเจ้าของยอมเว้นช่อง “ยังไม่รู้”. ความรู้ต้องเปลี่ยนการตัดสินใจ: เจ้าของเลิกจัดเรื่องเล่าที่เป็นไปได้เป็นข้อสรุป และไม่ใช้กรอบแบนแทนหลักฐานของที่ซ่อนจริง

ความจริงในเรื่องแต่ง: โมจิมีกล่องเก่าในห้อง เจ้าของวางของใหม่/อ่านงานวิจัย/เปลี่ยนป้าย โมจิเลือกกล่องเก่าตอนท้ายเป็นมุกแต่ง `F012`. ไม่เคยมีการทดลองของโมจิที่ควบคุมตัวแปรหรือพิสูจน์เหตุ. ความจริงทางความรู้: ข้อมูลบางส่วนรองรับพฤติกรรมต่อกรอบและประโยชน์ของที่ซ่อนในบริบทที่ศึกษา; เหตุที่แมวแต่ละตัวเลือกกล่องครั้งหนึ่งยังปิดคดีไม่ได้. Twist เปลี่ยนผู้ถูกสืบจาก “ความลับของแมว” เป็น “ความรีบสรุปของเจ้าของ” โดยไม่ลบสถานะสมมติฐาน

## ข้อตกลง VO / ซับ / ข้อความความรู้

แต่ละ beat มี VO ที่พูดจริงแยกจากซับย่อด้วยป้ายชัดเจน ซับที่คั่น `/` คือข้อความต่อเนื่องทีละช่วง ห้ามวางทั้งแถบพร้อมกัน. เป็น editorial cue list ยังไม่ใช่ subtitle file ที่ sync เสียง; ต้องมีซับไทยจาก frame 0 และคงบรรทัดปัจจุบันจนเปลี่ยนบรรทัด ห้ามเว้นว่างเพราะแบ่ง beat. ป้าย “เรื่องสมมติ”/“ภาพอธิบาย”/“สมมติฐาน” เป็นข้อความภาพตามบท จัดพื้นที่ให้พ้นซับโดย Mark. ใช้ Noto Sans Thai/Sarabun ตามกฎช่อง

นอกจากข้อความภาพที่ระบุในแต่ละบท ไม่เพิ่มกราฟ ตัวเลข หรือคำพูดอ้างเป็น direct quote. ชื่องานวิจัยใช้ชื่อย่อของผู้เขียน/ปีพร้อม source ID ใน credit ไม่เอา F/SRC IDs ขึ้นเป็นภาษาพากย์. แหล่งตรงและสถานะเข้าถึงดู research R1; แพรวอ้างตาม packet ไม่อ้างว่าเปิดอ่านต้นฉบับซ้ำเอง

## Handoff สำหรับโบ็ต แล้วจึงมาร์ค

โบ็ตตรวจ `ch01-script.md` **R5** ครบทั้ง 12 VO blocks ของ Long U01/U02 และ Short S01 แล้ว: supported/ready-for-storyboard ทางข้อเท็จจริง; ไม่พบ factual drift หรือการเปลี่ยน causal scope/uncertainty จากคำเชื่อมและประโยคที่ปรับ. C02–C06 คงผลตรวจ **R4** ใน `episode-fact-check.md`; หากแก้ claim หรือ surface ต่อ ให้ส่งตรวจผลกระทบ revision ใหม่ก่อน. ตาราง mapping แต่ละบทครอบคลุมกลุ่มประโยคที่ใช้ claim เดียวกัน; คำถามเชิงวาทศิลป์ยังต้องตรวจ implied claim. ไม่มี claims ใหม่ที่ตั้งใจให้เป็น fact นอก ledger. ถ้าพบ implication ใหม่ ให้เปิด `needs-research` แล้วส่งแพรว rewrite ห้ามถือว่าการวิจัยก่อนหน้าเป็นผลตรวจบท

ส่ง Mark เมื่อ script กับ fact-check ตรง revision และสถานะพร้อมเท่านั้น. เขารับเส้นเรื่อง ข้อที่ต้องเห็น สิ่งห้ามเฉลยก่อนเวลา และข้อจำกัดความรู้; เลือก framing/light/camera เอง. ไม่ lock แล็บเป็นสถานที่ทดลองจริง: ถ้าใช้ให้เป็นห้องอ่านหลักฐานของเจ้าของ. งานวิจัยเรื่องกรอบของ Smith ตีพิมพ์ในปี 2021; เก็บข้อมูลที่บ้านผู้เข้าร่วม. `room`/cat ใช้เป็นฐานได้ตาม research; lab/box/tape-square/Kanizsa/toy/evidence-board ยังต้องตรวจ/สร้าง library ก่อน production. แมว เจ้าของ interaction props 2D; กล่องหนึ่งภาพสมบูรณ์ต่อมุม; Boss ตรวจ contact/occlusion. ไม่มี runtime capability ที่เพิ่มด้วยเอกสารนี้

Ending Long และทุก Short: ค้างสาระ/มุกท้ายราว3s แล้วให้ผู้ทำ timeline เสนอ `_A_fade` และ `_B_loop`; loop กลับคำถามต้นเรื่องได้แต่ห้ามทำให้สมมติฐานกลายเป็นข้อสรุป. ยังไม่มี render หรือไฟล์ ending จริง
