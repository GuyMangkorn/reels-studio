## Long U01 — เหมือนกอด จึงพิสูจน์แล้วไหม? (0–45s)

### CATBOX-C05-U01-B01 · 0–10s

**VO:** “กล่องกอดแมวได้เหรอ? เจ้าของโมจิเจอคำอธิบายว่า ด้านข้างกล่องแตะตัวแล้วสบาย เหมือนมีอะไรกอด. ฟังแล้วอบอุ่นจนอยากใช้เป็นเฉลยสุดท้าย.”

**ซับ:** “กล่องกอดแมวได้เหรอ?” / “ข้อเสนอ: สัมผัสด้านข้างอาจทำให้สบาย”

**ข้อความภาพ:** “สมมติฐาน / ยังไม่ยืนยันกลไก” ตั้งแต่เริ่มอธิบาย ไม่ใส่ภาพแม่แมว/ฮอร์โมน/ความทรงจำในสมอง

### CATBOX-C05-U01-B02 · 10–23s

**VO:** “ผู้เชี่ยวชาญบางคนเสนอเรื่องสัมผัสด้านข้างจริง. แต่หลักฐานที่เราตรวจตอนนี้ ยังไม่เจองานทดลองในแมวที่แยกแรงกดออกจากการซ่อนหรือความอุ่น. เลยยังยืนยันไม่ได้ว่าแรงกดทำให้แมวเลือกกล่อง.”

**ซับ:** “มีข้อเสนอจากผู้เชี่ยวชาญ” / “ยังไม่พบการแยกทดลองแรงกดในหลักฐานชุดนี้”

**ข้อความภาพ:** “ข้อเสนอในการสัมภาษณ์ / ไม่ใช่ผลทดลองกลไก” ไม่จัดเป็นข้อสรุปจากpaperกล่องซ่อน

### CATBOX-C05-U01-B03 · 23–35s

**VO:** “ยิ่งคำว่า แมวจำอ้อมกอดแม่ได้ ยิ่งต้องระวัง. ในหลักฐานชุดนี้ เรายังไม่มีอะไรยืนยันแบบนั้น. อย่าเอาความทรงจำที่ฟังแล้วน่ารัก ไปใส่ในหัวแมวเหมือนเราอ่านใจได้.”

**ซับ:** “จำอ้อมกอดแม่? / ยังไม่มีหลักฐานยืนยันในชุดนี้” / “น่ารัก ไม่เท่ากับยืนยันแล้ว”

**เหตุการณ์:** ไม่แสดงflashbackแม่แมวแม้ติดคำถาม เพราะเสี่ยงคนดูจำภาพเป็นfact; ใช้ข้อความคำอ้างที่ถูกตั้งคำถามเท่านั้น

### CATBOX-C05-U01-B04 · 35–45s

**VO:** “เจ้าของเลยเก็บคำว่า อ้อมกอด ไว้เป็นคำเปรียบ. ส่วนแรงสัมผัสที่อาจทำให้สบาย ยังเป็นคำอธิบายที่ยืนยันไม่ได้. กล่องไม่ได้ถูกพิสูจน์ว่าไม่สบาย. แค่ยังยืนยันเหตุนี้ไม่ได้.”

**ซับ:** “คำเปรียบ ≠ ผลทดลอง” / “แรงสัมผัสอาจมีส่วน แต่ยังไม่ยืนยัน”

## Long U02 — เดินมาดู กับเลือกนั่ง ต่างกันไหม? (0–45s)

### CATBOX-C05-U02-B01 · 0–10s

**VO:** “ของใหม่เรียกแมวมาดูได้ แล้วไงต่อ? เจ้าของวางของชิ้นใหม่. โมจิเดินมาดม. เขาจ่อปากกาจะเขียนว่า เพราะอยากรู้อยากเห็น. แต่โมจิเดินออกไปก่อน.”

**ซับ:** “เดินมาดู แล้วเลือกอยู่ไหม?” / “เรื่องสมมติ: โมจิดมแล้วเดินออก”

**เหตุการณ์:** ป้าย “เรื่องสมมติ” ก่อนการดม; ปลูกCL05. ไม่บังคับพฤติกรรมให้เหมือนผลpaper

### CATBOX-C05-U02-B02 · 10–24s

**VO:** “มีงานศึกษาการสำรวจวัตถุใหม่ในแมวโต. มีแมวยี่สิบเอ็ดตัวในงานนี้. พวกมันได้เจอวัตถุใหม่. มีทั้งแบบเติมกลิ่นหนูและแบบไม่เติมกลิ่นหนู. นักวิจัยพบการสำรวจในทั้งสองแบบ. แต่วัตถุที่ใช้เป็นก้อนไม้หุ้มผ้า มีด้านเท่ากันทุกด้าน. ไม่ใช่กล่องเปิดให้นั่งข้างใน.”

**ซับ:** “งานสำรวจวัตถุใหม่ / แมวโต 21 ตัว” / “ไม้ทรงลูกบาศก์หุ้มผ้า” / “ไม่ใช่กล่องเปิดให้นั่ง”

**ข้อความภาพ:** “Machado & Genaro 2014 / ภาพอธิบายงานวิจัย”; ไม่วาดกล่องเปล่าแทนวัตถุไม้แล้วใช้จำนวน21ทับ

### CATBOX-C05-U02-B03 · 24–35s

**VO:** “ของใหม่อาจทำให้แมวเดินมาสำรวจได้. แต่ยังตอบไม่ได้ว่าทำไมถึงเลือกนั่ง หรืออยู่นาน. ถ้าพูดว่าเพราะสงสัย แล้วเหมาทั้งสองอย่าง ก็เกินจากหลักฐานที่มี.”

**ซับ:** “เหตุที่เดินมาสำรวจ” / “ยังไม่เท่ากับเหตุที่เลือกพัก”

### CATBOX-C05-U02-B04 · 35–45s

**VO:** “เจ้าของมองแฟ้มที่แยกไว้ แล้วเพิ่งเห็นปัญหา. เขาไม่ได้ขาดแค่คำตอบ. เขากำลังเอาคำตอบคนละเรื่องมาปนกัน. ถึงเวลาจัดแฟ้มใหม่แล้ว.”

**ซับ:** “คำตอบของคนละคำถาม” / “ได้เวลาจัดแฟ้มใหม่”
