# CATBOX-C04 — ตัวเลขยังปิดคดีไม่ได้

Script **R2** / research **R1** / `fiction-with-factual-knowledge`; draft-for-fact-check; ยังไม่อนุมัติบท. Long4:30–6:00โดยประมาณ; U01/U02เป้า45s; Short45s. Timing `estimated`, ไม่ audio-tested. กติกา [episode-script.md](episode-script.md), แหล่ง [research.md](research.md).

เหตุ→ผล: เจ้าของอยากใช้ความอุ่นอธิบายจบ → เจอช่วงอุณหภูมิที่ถูกแชร์ → ตรวจนิยามพบว่าไม่ใช่สิ่งเดียวกับความรู้สึกสบาย → คงความอุ่นเป็นหนึ่งสมมติฐานโดยไม่สรุปเหตุของกรอบหรือกล่องเฉพาะใบ. Payoff: ตัวเลขที่มีจริงในแหล่ง ไม่ทำให้คำแปลความหมายทุกแบบถูกตามไปด้วย

## Long U01 — ตัวเลขนั้นแปลว่าอะไร? (0–45s)

### CATBOX-C04-U01-B01 · 0–10s

**VO:** “เพราะกล่องอุ่น จบไหม? เจ้าของเจอตัวเลขสามสิบถึงสามสิบแปดองศา แล้วเกือบเขียนว่า แมวต้องอยู่ร้อนเท่านี้ถึงจะสบาย แต่ข้อสรุปนั้นใช้ไม่ได้”

**ซับ:** “เพราะกล่องอุ่น จบไหม?” / “30–38°C = ต้องอยู่ถึงสบาย? สรุปแบบนี้ไม่ได้”

**ข้อความภาพ:** ตัวเลขต้องอยู่กับคำถาม/คำห้ามสรุปตั้งแต่ปรากฏ ห้ามโชว์เดี่ยวเป็นค่าที่แนะนำ ป้าย “ตรวจคำอ้าง / ไม่ใช่คำแนะนำตั้งอุณหภูมิ”

### CATBOX-C04-U01-B02 · 10–25s

**VO:** “คำที่ถูกโยงมาคือ ช่วงเป็นกลางทางความร้อน หมายถึงช่วงอุณหภูมิรอบตัวที่สัตว์คงอุณหภูมิกายได้ โดยไม่ต้องเพิ่มการสร้างความร้อนจากการเผาผลาญ หรือเพิ่มการระบายความร้อนด้วยการระเหย นี่เป็นนิยามการทำงานของร่างกาย”

**ซับ:** “TNZ: ช่วงเป็นกลางทางความร้อน” / “คงอุณหภูมิกาย โดยไม่เพิ่มการสร้างความร้อน” / “หรือเพิ่มการระบายความร้อนด้วยการระเหย”

**ข้อความภาพ:** “นิยามทางสรีรวิทยา ≠ คะแนนความสบาย” และ “ภาพอธิบาย” ไม่ทำปรอทแนะนำหรือเส้นผลทดลองปลอม

### CATBOX-C04-U01-B03 · 25–36s

**VO:** “มันจึงไม่ใช่คำเดียวกับ อุณหภูมิที่แมวรู้สึกสบายหรือเลือกอยู่เสมอ รายงานอีเอฟเอสเอปีสองพันยี่สิบสามก็ทักท้วงการตีความช่วงสามสิบถึงสามสิบแปดนี้ เรายังเอามาปิดเป็นกฎสากลไม่ได้”

**ซับ:** “TNZ ไม่ใช่ช่วงที่เลือกอยู่เสมอ” / “EFSA 2023 ทักท้วงการตีความช่วงดังกล่าว”

### CATBOX-C04-U01-B04 · 36–45s

**VO:** “เจ้าของเลยเอาปากกาออกจากหน้าปัด ไม่ใช่ให้เราไปอุ่นห้องตามตัวเลข แต่ให้กลับมาถามว่า ตัวเลขนี้วัดอะไร และตอบคำถามที่เราถามจริงไหม”

**ซับ:** “ตัวเลขวัดอะไร?” / “ไม่ใช่คำแนะนำให้อุ่นห้องตามนี้”

**เหตุการณ์:** ไม่มีการปรับฮีตเตอร์/แอร์ในเรื่อง ไม่มีอ้างจำนวนแมวของงาน1970

## Long U02 — แล้วความอุ่นหมดความหมายไหม? (0–45s)

### CATBOX-C04-U02-B01 · 0–10s

**VO:** “แล้วกรอบเปล่าจะอุ่นตรงไหน? คำถามนี้ทำให้เจ้าของเกือบเหวี่ยงไปอีกข้างว่า ความอุ่นไม่เกี่ยวเลย แต่เรายังไม่ควรสรุปไกลขนาดนั้น”

**ซับ:** “แล้วกรอบเปล่าล่ะ?” / “ยังสรุปไม่ได้ว่าความอุ่นไม่เกี่ยวทุกกรณี”

**ข้อความภาพ:** “ข้อเดาของเจ้าของ” คู่กับประโยคความอุ่นไม่เกี่ยว และขีดออกในbeatเดียว

### CATBOX-C04-U02-B02 · 10–23s

**VO:** “ความอุ่นอาจเป็นหนึ่งปัจจัย มีข้อมูลเรื่องแมวหาวัสดุที่ช่วยเป็นฉนวนเมื่อหนาว แต่จากหลักฐานที่เรามี ยังไม่ได้แยกทดสอบว่าโมจิเลือกกล่องใบนี้เพราะความอุ่น หรือเพราะปัจจัยอื่น”

**ซับ:** “ความอุ่น: อาจเป็นหนึ่งปัจจัย” / “ยังไม่ยืนยันเหตุของกล่องใบนี้”

**เหตุการณ์:** ภาพโมจิเป็นfiction ไม่ทำthermal mapให้ดูเหมือนวัดจริง; คงป้าย “สมมติฐาน”

### CATBOX-C04-U02-B03 · 23–35s

**VO:** “กรอบกระดาษไม่มีผนังแบบกล่องให้กักพื้นที่รอบตัว มันจึงไม่ควรถูกอธิบายแทนกันง่าย ๆ แต่การเห็นบางตัวเลือกกรอบ ก็ไม่ได้หักล้างบทบาทความอุ่นในกล่องจริงทุกแบบ สิ่งเร้าต่างกัน ต้องถามแยกกัน”

**ซับ:** “กรอบไม่มีผนังแบบกล่อง” / “ผลของกรอบ ไม่ตัดสินทุกหน้าที่ของกล่อง”

### CATBOX-C04-U02-B04 · 35–45s

**VO:** “แฟ้มความอุ่นเลยถูกเก็บในกอง อาจเป็นไปได้ เจ้าของยังอยากได้ป้ายที่ฟังแล้วจบง่าย จนเจออีกประโยคหนึ่ง กล่องเหมือนอ้อมกอด… ฟังดูใช่ แปลว่าจริงไหม?”

**ซับ:** “อาจเป็นไปได้ ≠ พิสูจน์แล้ว” / “คำตอบที่ฟังดูใช่ จะจริงไหม?”

**Causal handoff:** อย่าพากย์ว่า “ตัดความอุ่นออกแล้ว” เพราะบทไม่ได้พิสูจน์ว่าเป็นศูนย์

## Short S01 — แมวต้องอยู่ 30–38 องศาจริงไหม? (45s)

### CATBOX-C04-S01-B01 · 0–9s

**VO:** “สามสิบถึงสามสิบแปดองศา แมวต้องอยู่เท่านี้ถึงสบายจริงเหรอ? สรุปแบบนั้นไม่ได้ และนี่ไม่ใช่คำแนะนำให้อุ่นห้อง”

**ซับ:** “30–38°C = ต้องอยู่ถึงสบาย?” / “สรุปแบบนี้ไม่ได้ / ไม่ใช่คำแนะนำอุ่นห้อง”

### CATBOX-C04-S01-B02 · 9–23s

**VO:** “ช่วงเป็นกลางทางความร้อน คือช่วงอุณหภูมิรอบตัวที่คงอุณหภูมิกายได้ โดยไม่เพิ่มการสร้างความร้อนจากการเผาผลาญ หรือการระบายความร้อนด้วยการระเหย ไม่ใช่ช่วงที่แมวเลือกอยู่เสมอ”

**ซับ:** “TNZ เป็นนิยามทางสรีรวิทยา” / “ไม่ใช่ช่วงที่แมวเลือกอยู่เสมอ”

### CATBOX-C04-S01-B03 · 23–34s

**VO:** “อีเอฟเอสเอทักท้วงการตีความช่วงตัวเลขนี้ด้วย ความอุ่นอาจเป็นหนึ่งปัจจัย แต่ยังไม่ได้พิสูจน์ว่าเป็นเหตุให้เลือกกล่องทุกใบ”

**ซับ:** “EFSA ทักท้วงการตีความช่วงนี้” / “ความอุ่น: หนึ่งสมมติฐาน”

### CATBOX-C04-S01-B04 · 34–45s

**VO:** “ก่อนใช้ตัวเลขปิดคดี ลองถามว่าเขาวัดอะไร ตัวเลขทางร่างกาย ไม่ใช่คำตอบแทนความรู้สึกแมวทุกตัว”

**ซับ:** “ตัวเลขวัดอะไร / ตอบคำถามไหน?”

**ท้าย:** เสียงจบเป้าราว42s ค้าง3s; ตัวเลขทุกครั้งมีqualificationในภาพ ไม่ใช้thumbnailเลขเปล่า; ไม่มีฮีตเตอร์หรือthermal map. ชื่อShortเป็นคำถามตอบด้วยข้อจำกัดทันที
