# CATBOX-C04 — ตัวเลขยังปิดคดีไม่ได้

Script **R4** / research **R1** / `fiction-with-factual-knowledge`; draft-for-fact-check; ยังไม่อนุมัติบท. Long4:30–6:00โดยประมาณ; U01/U02เป้า45s; Short45s. Timing `estimated`, ไม่ audio-tested. กติกา [episode-script.md](episode-script.md), แหล่ง [research.md](research.md).

เหตุ→ผล: เจ้าของอยากใช้ความอุ่นอธิบายจบ → เจอช่วงอุณหภูมิที่ถูกแชร์ → ตรวจนิยามพบว่าไม่ใช่สิ่งเดียวกับความรู้สึกสบาย → คงความอุ่นเป็นหนึ่งสมมติฐานโดยไม่สรุปเหตุของกรอบหรือกล่องเฉพาะใบ. Payoff: ตัวเลขที่มีจริงในแหล่ง ไม่ทำให้คำแปลความหมายทุกแบบถูกตามไปด้วย

## Long U01 — ตัวเลขนั้นแปลว่าอะไร? (0–45s)

### CATBOX-C04-U01-B01 · 0–10s

**VO:** “เพราะกล่องอุ่น จบไหม? เจ้าของเจอช่วงอุณหภูมิที่คนชอบพูดถึง. ตัวเลขต้นช่วงคือสามสิบองศาเซลเซียส. ปลายอีกด้านคือสามสิบแปดองศาเซลเซียส. เขาเกือบเขียนว่าแมวต้องอยู่ร้อนเท่านี้ถึงสบาย. แต่สรุปแบบนั้นไม่ได้.”

**ซับ:** “เพราะกล่องอุ่น จบไหม?” / “30–38°C = ต้องอยู่ถึงสบาย? สรุปแบบนี้ไม่ได้”

**ข้อความภาพ:** ตัวเลขต้องอยู่กับคำถาม/คำห้ามสรุปตั้งแต่ปรากฏ ห้ามโชว์เดี่ยวเป็นค่าที่แนะนำ ป้าย “ตรวจคำอ้าง / ไม่ใช่คำแนะนำตั้งอุณหภูมิ”

### CATBOX-C04-U01-B02 · 10–25s

**VO:** “ตัวเลขนี้พูดถึงช่วงอุณหภูมิรอบตัวที่ร่างกายคุมอุณหภูมิได้เอง. ไม่ต้องเร่งเผาผลาญพลังงานเพื่อสร้างความร้อนเพิ่ม. หรือเร่งระบายความร้อนออกด้วยการระเหย. นี่เป็นคำอธิบายว่าร่างกายทำงานยังไง.”

**ซับ:** “TNZ: ช่วงเป็นกลางทางความร้อน” / “คงอุณหภูมิกาย โดยไม่เพิ่มการสร้างความร้อน” / “หรือเพิ่มการระบายความร้อนด้วยการระเหย”

**ข้อความภาพ:** “นิยามทางสรีรวิทยา ≠ คะแนนความสบาย” และ “ภาพอธิบาย” ไม่ทำปรอทแนะนำหรือเส้นผลทดลองปลอม

### CATBOX-C04-U01-B03 · 25–36s

**VO:** “ช่วงนี้ไม่ได้แปลว่าแมวจะสบายหรือเลือกอยู่ตรงนั้นเสมอ. รายงานอีเอฟเอสเอออกในปีสองพันยี่สิบสาม. รายงานนั้นทักท้วงวิธีอ่านช่วงตัวเลขนี้. ช่วงนี้เริ่มที่สามสิบองศาเซลเซียส. ปลายช่วงคือสามสิบแปดองศาเซลเซียส. เลยยังเอาไปตั้งเป็นกฎของแมวทุกตัวไม่ได้.”

**ซับ:** “TNZ ไม่ใช่ช่วงที่เลือกอยู่เสมอ” / “EFSA 2023 ทักท้วงการตีความช่วงดังกล่าว”

### CATBOX-C04-U01-B04 · 36–45s

**VO:** “เจ้าของเลยวางปากกาลงจากหน้าปัด. ไม่ใช่จะชวนให้เราไปอุ่นห้องตามตัวเลข. แต่อยากให้ถามก่อนว่า ตัวเลขนี้วัดอะไร. มันตอบคำถามที่เราถามจริงไหม?”

**ซับ:** “ตัวเลขวัดอะไร?” / “ไม่ใช่คำแนะนำให้อุ่นห้องตามนี้”

**เหตุการณ์:** ไม่มีการปรับฮีตเตอร์/แอร์ในเรื่อง ไม่มีอ้างจำนวนแมวของงาน1970

## Long U02 — แล้วความอุ่นหมดความหมายไหม? (0–45s)

### CATBOX-C04-U02-B01 · 0–10s

**VO:** “แล้วกรอบเปล่าจะอุ่นตรงไหน? คำถามนี้ทำให้เจ้าของเกือบเหวี่ยงไปอีกทางว่า ความอุ่นไม่เกี่ยวเลย. แต่ตอนนี้ก็ยังสรุปอย่างนั้นไม่ได้.”

**ซับ:** “แล้วกรอบเปล่าล่ะ?” / “ยังสรุปไม่ได้ว่าความอุ่นไม่เกี่ยวทุกกรณี”

**ข้อความภาพ:** “ข้อเดาของเจ้าของ” คู่กับประโยคความอุ่นไม่เกี่ยว และขีดออกในbeatเดียว

### CATBOX-C04-U02-B02 · 10–23s

**VO:** “ความอุ่นอาจเป็นปัจจัยหนึ่ง. มีข้อมูลว่าแมวหาวัสดุที่ช่วยเก็บความอุ่นเวลาเจออากาศหนาว. แต่จากงานที่เรามี เรายังแยกไม่ได้ว่าโมจิเลือกกล่องนี้เพราะอุ่นหรือเพราะอย่างอื่น.”

**ซับ:** “ความอุ่น: อาจเป็นหนึ่งปัจจัย” / “ยังไม่ยืนยันเหตุของกล่องใบนี้”

**เหตุการณ์:** ภาพโมจิเป็นfiction ไม่ทำthermal mapให้ดูเหมือนวัดจริง; คงป้าย “สมมติฐาน”

### CATBOX-C04-U02-B03 · 23–35s

**VO:** “กรอบกระดาษไม่มีผนังให้หลบเหมือนกล่องจริง. เราเลยเอามาแทนกันง่าย ๆ ไม่ได้. แต่การเห็นแมวบางตัวเลือกกรอบ ก็ไม่ได้แปลว่าความอุ่นไม่มีส่วนในกล่องจริง. สิ่งเร้าต่างกัน ต้องถามแยกกัน.”

**ซับ:** “กรอบไม่มีผนังแบบกล่อง” / “ผลของกรอบ ไม่ตัดสินทุกหน้าที่ของกล่อง”

### CATBOX-C04-U02-B04 · 35–45s

**VO:** “เจ้าของเลยเก็บเรื่องความอุ่นไว้ในกอง อาจเป็นไปได้. เขายังอยากได้ป้ายที่ฟังแล้วจบง่าย. จนเจอคำอธิบายอีกอัน. กล่องเหมือนอ้อมกอด… ฟังดูใช่. แล้วมันจริงไหม?”

**ซับ:** “อาจเป็นไปได้ ≠ พิสูจน์แล้ว” / “คำตอบที่ฟังดูใช่ จะจริงไหม?”

**Causal handoff:** อย่าพากย์ว่า “ตัดความอุ่นออกแล้ว” เพราะบทไม่ได้พิสูจน์ว่าเป็นศูนย์

## Short S01 — แมวต้องอยู่ 30–38 องศาจริงไหม? (45s)

### CATBOX-C04-S01-B01 · 0–9s

**VO:** “ช่วงนี้เริ่มที่สามสิบองศาเซลเซียส. ปลายอยู่ที่สามสิบแปดองศาเซลเซียส. แมวต้องอยู่เท่านี้ถึงจะสบายจริงเหรอ? สรุปแบบนั้นไม่ได้. นี่ไม่ใช่คำแนะนำให้อุ่นห้อง.”

**ซับ:** “30–38°C = ต้องอยู่ถึงสบาย?” / “สรุปแบบนี้ไม่ได้ / ไม่ใช่คำแนะนำอุ่นห้อง”

### CATBOX-C04-S01-B02 · 9–23s

**VO:** “ช่วงนี้ร่างกายยังคุมอุณหภูมิตัวเองได้. ไม่ต้องเร่งเผาผลาญพลังงานเพื่อสร้างความร้อนเพิ่ม. หรือเร่งระบายความร้อนออกด้วยการระเหย. แต่นี่ไม่ได้บอกว่าแมวจะเลือกอยู่ตรงนั้นเสมอ.”

**ซับ:** “TNZ เป็นนิยามทางสรีรวิทยา” / “ไม่ใช่ช่วงที่แมวเลือกอยู่เสมอ”

### CATBOX-C04-S01-B03 · 23–34s

**VO:** “รายงานอีเอฟเอสเอทักท้วงการตีความตัวเลขช่วงนี้. ความอุ่นอาจมีส่วน. แต่ยังไม่มีหลักฐานว่ามันเป็นเหตุให้แมวเลือกกล่องทุกใบ.”

**ซับ:** “EFSA ทักท้วงการตีความช่วงนี้” / “ความอุ่น: หนึ่งสมมติฐาน”

### CATBOX-C04-S01-B04 · 34–45s

**VO:** “ก่อนเอาตัวเลขมาปิดคดี ลองถามว่ามันวัดอะไร. มันบอกการทำงานของร่างกาย. ไม่ได้ตอบแทนความรู้สึกของแมวทุกตัว.”

**ซับ:** “ตัวเลขวัดอะไร / ตอบคำถามไหน?”

**ท้าย:** เสียงจบเป้าราว42s ค้าง3s; ตัวเลขทุกครั้งมีqualificationในภาพ ไม่ใช้thumbnailเลขเปล่า; ไม่มีฮีตเตอร์หรือthermal map. ชื่อShortเป็นคำถามตอบด้วยข้อจำกัดทันที
