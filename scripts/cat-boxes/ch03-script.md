# CATBOX-C03 — ที่พักหรือฐานซุ่ม

Script **R2** / research **R1** / `fiction-with-factual-knowledge`; draft-for-fact-check; ยังไม่อนุมัติบท. Long3:00–4:30โดยประมาณ; U01/U02เป้า45s; Short45s. Timing `estimated`, ไม่ audio-tested. อ่านกติกา [episode-script.md](episode-script.md), ledger [research.md](research.md).

เหตุ→ผล: เจ้าของเห็นโมจิพุ่งออกตามของเล่น → เกือบใช้การกระทำนั้นอธิบายทุกการนั่ง → กลับไปแยกหน้าที่ที่ทำได้จากเหตุที่เลือกใช้. Payoff: วัตถุเดียวใช้ได้หลายหน้าที่โดยยังไม่รู้แรงจูงใจทุกครั้ง

## Long U01 — โมจิรออะไร? (0–45s)

### CATBOX-C03-U01-B01 · 0–8s

**VO:** “นั่งพัก หรือรอพุ่ง? โมจิอยู่ในกล่องนิ่ง ๆ เจ้าของเพิ่งจะจดว่า พักผ่อน ของเล่นก็เลื่อนผ่าน แล้วโมจิพุ่งตาม!”

**ซับ:** “นั่งพัก หรือรอพุ่ง?” / “ของเล่นผ่าน… โมจิพุ่ง!”

**เหตุการณ์:** เสียงของเล่นก่อนพุ่งเล็กน้อยให้รับการเปลี่ยนจังหวะ; ป้าย “เรื่องสมมติ” ตั้งแต่B01 ไม่ใช้แมวหรือเหยื่อมีชีวิตในการสาธิต

### CATBOX-C03-U01-B02 · 8–21s

**VO:** “อ๋อ กล่องเป็นฐานล่า! เขาเกือบปิดแฟ้มอีกรอบ แมวมีพฤติกรรมย่อง ไล่ และพุ่งจริง แนวทางด้านสิ่งแวดล้อมสำหรับแมวก็พูดถึงการเปิดโอกาสให้ทำพฤติกรรมล่าผ่านการเล่น แต่ช้าก่อน”

**ซับ:** “ย่อง / ไล่ / พุ่ง เป็นพฤติกรรมที่พบจริง” / “ยังปิดแฟ้มไม่ได้”

**ข้อความภาพ:** คำ “กล่องเป็นฐานล่า!” เป็นความคิดเจ้าของพร้อม “ข้อเดาของเจ้าของ” ในbeatเดียว ไม่ขึ้นเป็นหัวข้อfact

### CATBOX-C03-U01-B03 · 21–34s

**VO:** “สิ่งที่เราเห็นในเรื่องนี้คือ โมจิพุ่งตามของเล่น ส่วนประโยคว่า มันเข้าไปในกล่องตั้งแต่แรกเพื่อซุ่ม นั่นเป็นการเดาเพิ่ม กล่องอาจใช้เป็นที่ซุ่มเล่นได้ แต่ยังไม่ใช่เหตุผลที่ยืนยันแล้วของการนั่งทุกครั้ง”

**ซับ:** “เห็น: พุ่งตามของเล่น” / “เดา: เข้าไปเพื่อซุ่มตั้งแต่แรก” / “ที่ซุ่มเล่น: หนึ่งสมมติฐาน”

**เหตุการณ์:** ปลูกCL04 เจ้าของจดการกระทำก่อนเขียนเหตุแล้วชะงัก; คำ “สมมติฐาน” ต้องอยู่พร้อมการเสนอเหตุ

### CATBOX-C03-U01-B04 · 34–45s

**VO:** “พอของเล่นหยุด โมจิก็นั่งต่อ เจ้าของเลยเปลี่ยนคำถาม จาก กล่องมีไว้ทำอะไรอย่างเดียว เป็น กล่องใบเดียวทำอะไรได้บ้าง เพราะภาพแค่ตอนพุ่ง ยังอธิบายทุกตอนที่นิ่งไม่ได้”

**ซับ:** “กล่องใบเดียวทำอะไรได้บ้าง?” / “ภาพตอนพุ่ง ไม่ตอบทุกตอนที่นิ่ง”

**เหตุการณ์:** โมจินั่งต่อเป็นfiction ไม่ใช่control condition; ห้ามกราฟเปรียบ “พัก/ล่า” จากเหตุการณ์นี้

## Long U02 — แค่บังตัวก็มีหน้าที่แล้ว? (0–45s)

### CATBOX-C03-U02-B01 · 0–10s

**VO:** “แค่บังตัว ก็เป็นคนละเรื่องแล้วไหม? ลองมองกล่องที่มีหลังคาและช่องเข้า กับกรอบบนพื้น อันหนึ่งมีส่วนบังตัว อีกอันมีแค่ขอบที่มองเห็น ความต่างนี้ไม่ได้หายไปเพราะแมวนั่งเหมือนกัน”

**ซับ:** “กล่องที่หลบได้ กับกรอบแบน” / “หน้าที่ทางกายภาพต่างกัน”

**ข้อความภาพ:** “ภาพอธิบายหน้าที่” ไม่สลับกล่องเปิดที่เห็นตัวหมดกับที่หลบมีหลังคาในช่วงอธิบาย

### CATBOX-C03-U02-B02 · 10–23s

**VO:** “แนวทางความต้องการด้านสิ่งแวดล้อมของแมวให้ความสำคัญกับพื้นที่ปลอดภัย และยกกล่องที่จัดเป็นที่หลบเป็นตัวอย่าง นี่ช่วยให้เรามองว่ากล่องไม่ได้มีแค่รูปสี่เหลี่ยม มันยังจัดพื้นที่ให้หลบจากสายตาได้”

**ซับ:** “แนวทางพูดถึงพื้นที่ปลอดภัย” / “กล่องที่จัดเป็นที่หลบ เป็นตัวอย่างหนึ่ง”

**ข้อความภาพ:** “AAFP/ISFM 2013 / Pillar1: safe place” ไม่เขียน “แมวปลอดภัยทันทีทุกตัว”

### CATBOX-C03-U02-B03 · 23–35s

**VO:** “แต่คำแนะนำเรื่องพื้นที่ปลอดภัย ไม่ได้แปลว่าเรารู้ความรู้สึกของโมจิตอนนี้ มันอาจพัก อาจเล่น หรือเปลี่ยนการใช้ระหว่างอยู่ในนั้นได้ เหตุเฉพาะครั้งยังเป็นคำถาม ไม่ใช่ใบอนุญาตให้เราเลือกคำตอบแทนมัน”

**ซับ:** “หน้าที่ที่ทำได้ ≠ เหตุเฉพาะที่พิสูจน์แล้ว” / “เรื่องโมจิยังเป็นเรื่องสมมติ”

### CATBOX-C03-U02-B04 · 35–45s

**VO:** “เจ้าของจึงเก็บคำว่า ที่ซุ่ม ไว้ในกองสมมติฐาน ไม่ทิ้ง แต่ไม่ประทับตราว่ายืนยันแล้ว เหลืออีกคำอธิบายที่ฟังดูง่ายกว่า กล่องมันอุ่นหรือเปล่า?”

**ซับ:** “ที่ซุ่ม: อาจเป็นหนึ่งเหตุ” / “แล้วเรื่องความอุ่นล่ะ?”

**Causal handoff:** แยกสิ่งที่กล่องทำได้แล้วจึงค้นสมมติฐานอื่น ไม่ปล่อยให้มุกพุ่งยืนยันสาเหตุ

## Short S01 — แมวในกล่องกำลังซุ่มอยู่ไหม? (45s)

### CATBOX-C03-S01-B01 · 0–8s

**VO:** “นั่งพัก หรือรอพุ่ง? ในเรื่องนี้ โมจินั่งในกล่อง พอของเล่นผ่านก็พุ่งตาม เจ้าของรีบจดว่า กล่องคือฐานล่า”

**ซับ:** “นั่งพัก หรือรอพุ่ง?” / “เรื่องสมมติ: เจ้าของรีบสรุป”

### CATBOX-C03-S01-B02 · 8–21s

**VO:** “แมวมีพฤติกรรมย่อง ไล่ และพุ่งจริง กล่องก็อาจเป็นที่ซุ่มเล่นได้ แต่เราเห็นแค่การพุ่ง ยังไม่รู้ว่าตอนเข้าไป มันตั้งใจจะซุ่ม หรือเข้าไปด้วยเหตุอื่นก่อน”

**ซับ:** “ย่อง / ไล่ / พุ่ง พบจริง” / “เข้าไปเพื่อซุ่ม: ยังเป็นสมมติฐาน”

### CATBOX-C03-S01-B03 · 21–33s

**VO:** “กล่องที่จัดให้หลบได้ยังมีส่วนบังตัว ต่างจากกรอบแบนบนพื้น วัตถุเดียวจึงอาจมีมากกว่าหนึ่งหน้าที่ การพุ่งครั้งเดียวไม่ได้อธิบายทุกครั้งที่แมวนั่งนิ่ง”

**ซับ:** “ที่หลบจริงมีส่วนบังตัว” / “ครั้งที่พุ่ง ไม่อธิบายทุกครั้งที่นิ่ง”

### CATBOX-C03-S01-B04 · 33–45s

**VO:** “เจ้าของแก้โน้ตใหม่ เห็นว่าพุ่งตามของเล่น ส่วนเข้าไปเพราะอะไร ยังไม่รู้ กล่องอาจเป็นฐานซุ่ม แต่ยังปิดคดีทุกการนั่งไม่ได้”

**ซับ:** “เห็นการกระทำ / ยังไม่รู้เหตุที่เข้าไป”

**ท้าย:** VOจบเป้าราว42s ค้าง3s; พุ่ง/กลับนั่งเป็นเรื่องแต่งทุกเวอร์ชัน มีป้ายให้เห็นก่อนเกิดเหตุ ไม่ทำเป็นทดลองเปรียบเทียบจริง
