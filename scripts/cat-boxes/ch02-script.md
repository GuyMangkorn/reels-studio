## Long U01 — ที่หลบช่วยได้แค่ไหน? (0–45s)

### CATBOX-C02-U01-B01 · 0–9s

**VO:** “กล่องช่วยอะไรได้บ้าง? เจ้าของโมจิเคยคิดว่ากล่องเป็นแค่ที่นั่ง. แต่ถ้ามีที่ให้หลบ มันก็อาจทำอย่างอื่นได้. ลองไปดูงานในศูนย์พักพิงกัน.”

**ซับ:** “กล่องช่วยอะไรได้บ้าง?” / “มองหน้าที่ของที่หลบ”

**เหตุการณ์:** เปลี่ยนจากเรื่องโมจิเป็น “ภาพอธิบายงานวิจัย”; ไม่ให้สัตว์สมมติรับบทตัวอย่างจริงแบบไม่มีป้าย

### CATBOX-C02-U01-B02 · 9–23s

**VO:** “งานศึกษาจากศูนย์พักพิงในเนเธอร์แลนด์ตีพิมพ์ในปีสองพันสิบสี่. เขาสุ่มแมวที่เพิ่งเข้าศูนย์พักพิงสิบเก้าตัว. สิบตัวได้ที่ซ่อน. อีกเก้าตัวไม่ได้. ตามดูกันสิบสี่วัน. เขาวัดคะแนนความเครียดจากพฤติกรรม. ไม่ได้ฟังคำตอบจากแมวเอง.”

**ซับ:** “2014 / 19 ตัว / ติดตาม 14 วัน” / “มีที่ซ่อน 10 / ไม่มี 9” / “วัดคะแนนจากพฤติกรรม”

**ข้อความภาพ:** “Vinke และคณะ 2014 / Cat-Stress-Score (CSS)” พร้อมตัวเลขตามVO ไม่ใส่กราฟรายวันหรือค่าที่ไม่มีในpacket

### CATBOX-C02-U01-B03 · 23–35s

**VO:** “ในวันที่สาม กลุ่มมีที่ซ่อนได้คะแนนต่ำกว่า. ผลทดสอบจับความต่างได้. วันที่สี่ก็ยังได้ผลแบบนี้. พอถึงวันที่สิบสี่ ค่าเฉลี่ยของกลุ่มที่มีที่ซ่อนกับกลุ่มที่ไม่มีเท่ากัน. แต่กลุ่มมีที่ซ่อนลงมาถึงระดับนั้นตั้งแต่ประมาณวันที่สาม.”

**ซับ:** “วันที่ 3–4: กลุ่มมีที่ซ่อน CSS ต่ำกว่า” / “วันที่ 14: ค่าเฉลี่ยเท่ากัน” / “กลุ่มมีที่ซ่อนถึงระดับนั้นราววันที่ 3”

**ข้อความภาพ:** บรรทัดผลวันที่3–4มี “อย่างมีนัยสำคัญ” ชัด อ่านไม่ทันให้ลดข้อความอื่น ไม่ย่อจนเหลือแค่ลูกศรความเครียด

### CATBOX-C02-U01-B04 · 35–45s

**VO:** “ผลนี้รองรับว่า ที่ซ่อนช่วยให้แมวปรับตัวเร็วขึ้นในศูนย์พักพิงที่ดูในงานนี้. ไม่ได้รับรองว่ากล่องช่วยจัดการความเครียดได้ทุกแบบ. และไม่ได้บอกอะไรเกี่ยวกับกรอบเทป.”

**ซับ:** “ช่วยการปรับตัวในบริบทที่ศึกษา” / “ยังใช้ยืนยันผลของกรอบเทปไม่ได้”

## Long U02 — คะแนนดีขึ้น แปลว่าดีขึ้นทุกด้านไหม? (0–45s)

### CATBOX-C02-U02-B01 · 0–10s

**VO:** “คะแนนดีขึ้น แล้วอย่างอื่นล่ะ? เจ้าของเกือบเขียนว่า กล่องช่วยทุกอย่าง แล้วก็ชะงัก. งานแต่ละชิ้นวัดคนละเรื่อง. ต้องดูด้วยว่ามีอะไรที่ไม่ได้ดีขึ้นตาม.”

**ซับ:** “คะแนนดีขึ้น แล้วอย่างอื่นล่ะ?” / “ต้องดูสิ่งที่งานวัดจริง”

**เหตุการณ์:** คำ “ช่วยทุกอย่าง” ต้องถูกขีดออกในbeatเดียวกัน ไม่ปล่อยเป็นบรรทัดสรุปจริง

### CATBOX-C02-U02-B02 · 10–24s

**VO:** “งานติดตามอีกชิ้นตีพิมพ์ในปีสองพันสิบเก้า. มีแมวยี่สิบสามตัว. สิบสองตัวมีที่ซ่อน. อีกสิบเอ็ดตัวไม่มี. เขาวัดคะแนนกับน้ำหนักในสิบสองวันแรก. กลุ่มที่มีที่ซ่อนคะแนนความเครียดลดเร็วกว่า. แต่ผลทดสอบจับความต่างเรื่องน้ำหนักที่ลดไม่ได้.”

**ซับ:** “อีกงาน: 2019 / 23 ตัว” / “คะแนนกับน้ำหนัก: 12 วันแรก” / “มีที่ซ่อน 12 / ไม่มี 11” / “CSS ลดเร็วกว่า” / “การลดน้ำหนัก: ไม่พบความต่างอย่างมีนัยสำคัญ”

**ข้อความภาพ:** “van der Leij และคณะ 2019”; ห้ามรวมตัวอย่างกับ2014 ให้ป้ายปีชัดตลอดช่วงเปรียบ

### CATBOX-C02-U02-B03 · 24–35s

**VO:** “ผลทดสอบยังจับความต่างเรื่องการรับเลี้ยงหรือระยะพักในศูนย์ไม่ได้. จับความต่างไม่ได้ ไม่ได้พิสูจน์ว่าไม่มีผล. แค่เตือนว่าอย่าเพิ่งบอกว่ากล่องทำให้ทุกอย่างดีขึ้นแน่ ๆ.”

**ซับ:** “การรับเลี้ยง / ระยะพัก: ไม่พบความต่างอย่างมีนัยสำคัญ” / “ไม่พบความต่าง ≠ พิสูจน์ว่าผลเป็นศูนย์”

### CATBOX-C02-U02-B04 · 35–45s

**VO:** “เจ้าของเลยแยกแฟ้มเป็น ผลที่วัดได้ กับ สิ่งที่ยังเดา. กล่องจริงมีที่ให้หลบ. แต่กรอบแบนบังตัวไม่ได้. ถึงแมวนั่งคล้ายกัน ก็ไม่ควรเหมารวมว่าประโยชน์เหมือนกัน.”

**ซับ:** “ผลที่วัด / สิ่งที่เดา” / “กล่องกับกรอบ ทำหน้าที่ไม่ครบเหมือนกัน”

**เหตุการณ์:** ปลูกCL03 สองกองแฟ้มอยู่ต่อไป ไม่เพิ่มข้อมูล cortisol/ภูมิคุ้มกัน หรือสถานพยาบาล

## Short S01 — กล่องช่วยแมวได้แค่ไหน? (45s)

### CATBOX-C02-S01-B01 · 0–8s

**VO:** “กล่องช่วยแมวได้แค่ไหน? มีงานเรื่องที่ซ่อนจริง. แต่คำว่า ช่วย ไม่ได้แปลว่าทุกอย่างดีขึ้น.”

**ซับ:** “กล่องช่วยแมวได้แค่ไหน?” / “ช่วยบางด้าน ไม่ใช่ทุกอย่าง”

### CATBOX-C02-S01-B02 · 8–22s

**VO:** “งานศึกษาศูนย์พักพิงตีพิมพ์ในปีสองพันสิบสี่. เขาสุ่มแมวสิบเก้าตัว. สิบตัวได้ที่ซ่อน. อีกเก้าตัวไม่ได้. ติดตามกันสิบสี่วัน. วันที่สาม คะแนนความเครียดจากพฤติกรรมของกลุ่มมีที่ซ่อนต่ำกว่า. วันที่สี่ก็ยังต่ำกว่า. ผลทดสอบจับความต่างได้.”

**ซับ:** “2014 / 19 ตัว / 14 วัน” / “วันที่ 3–4: CSS ต่ำกว่าอย่างมีนัยสำคัญ”

### CATBOX-C02-S01-B03 · 22–34s

**VO:** “แต่งานอีกชิ้นตีพิมพ์ในปีสองพันสิบเก้า. แม้คะแนนจะลดเร็วกว่าในกลุ่มมีที่ซ่อน. ผลทดสอบจับความต่างเรื่องน้ำหนักที่ลด การรับเลี้ยง หรือระยะพักในศูนย์ไม่ได้. จึงยังบอกไม่ได้ว่ากล่องแก้ได้ทุกเรื่อง.”

**ซับ:** “2019: คะแนนลดเร็วกว่า” / “ผลลัพธ์อื่นที่วัด: ไม่พบความต่างอย่างมีนัยสำคัญ”

### CATBOX-C02-S01-B04 · 34–45s

**VO:** “คำตอบคือ ที่ซ่อนช่วยให้แมวปรับตัวในที่พักพิงที่ดูในงานนี้. นี่เป็นผลจากที่ซ่อนจริง. ไม่ได้แปลว่ากรอบเทปช่วยเหมือนกัน.”

**ซับ:** “หลักฐานของที่ซ่อน / ยังไม่ใช่หลักฐานของกรอบเทป”

**ท้าย:** เสียงจบเป้าราว42s ค้าง3s. ข้อความภาพชื่อปีและคำ “ภาพอธิบายงานวิจัย” ตามLong; ไม่มีกราฟแต่ง
