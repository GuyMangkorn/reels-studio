# CATBOX-C05 — คำตอบที่น่ากอด

Script **R2** / research **R1** / `fiction-with-factual-knowledge`; draft-for-fact-check; ยังไม่อนุมัติบท. Long6:00–7:30โดยประมาณ; U01/U02เป้า45s; Short45s. Timing `estimated`, ไม่ audio-tested. กติกา [episode-script.md](episode-script.md), ledger [research.md](research.md).

เหตุ→ผล: เจ้าของชอบคำอธิบายอ้อมกอด → ตรวจพบเพียงข้อเสนอไม่ใช่การแยกทดลองแรงกด → หันดูความใหม่ → แยกเหตุที่เดินมาสำรวจกับเหตุที่อยู่ต่อ. Payoff: คำอธิบายน่ารักยังต้องมีหลักฐาน และงานสำรวจวัตถุไม่ใช่งานเลือกนั่งกล่อง

## Long U01 — เหมือนกอด จึงพิสูจน์แล้วไหม? (0–45s)

### CATBOX-C05-U01-B01 · 0–10s

**VO:** “กล่องกอดแมวได้เหรอ? เจ้าของโมจิเจอคำอธิบายว่า ข้างกล่องแตะตัวแล้วสบาย เหมือนมีอะไรกอด ฟังแล้วอบอุ่นจนอยากเอามาเป็นเฉลยสุดท้าย”

**ซับ:** “กล่องกอดแมวได้เหรอ?” / “ข้อเสนอ: สัมผัสด้านข้างอาจทำให้สบาย”

**ข้อความภาพ:** “สมมติฐาน / ยังไม่ยืนยันกลไก” ตั้งแต่เริ่มอธิบาย ไม่ใส่ภาพแม่แมว/ฮอร์โมน/ความทรงจำในสมอง

### CATBOX-C05-U01-B02 · 10–23s

**VO:** “มีผู้เชี่ยวชาญเสนอเรื่องสัมผัสด้านข้างจริง แต่หลักฐานที่เราตรวจในตอนนี้ ยังไม่พบการทดลองแมวที่แยกแรงกดออกจากการซ่อนหรืออุณหภูมิ เพื่อยืนยันว่าแรงนั้นคือเหตุที่ทำให้เลือกกล่อง”

**ซับ:** “มีข้อเสนอจากผู้เชี่ยวชาญ” / “ยังไม่พบการแยกทดลองแรงกดในหลักฐานชุดนี้”

**ข้อความภาพ:** “ข้อเสนอในการสัมภาษณ์ / ไม่ใช่ผลทดลองกลไก” ไม่จัดเป็นข้อสรุปจากpaperกล่องซ่อน

### CATBOX-C05-U01-B03 · 23–35s

**VO:** “ยิ่งประโยคว่า มันจำอ้อมกอดแม่ได้ เรายังไม่มีหลักฐานยืนยันในชุดนี้ด้วย อย่าเอาความทรงจำที่เล่าแล้วน่ารัก ไปใส่ให้แมวเหมือนเราอ่านมันออก”

**ซับ:** “จำอ้อมกอดแม่? / ยังไม่มีหลักฐานยืนยันในชุดนี้” / “น่ารัก ไม่เท่ากับยืนยันแล้ว”

**เหตุการณ์:** ไม่แสดงflashbackแม่แมวแม้ติดคำถาม เพราะเสี่ยงคนดูจำภาพเป็นfact; ใช้ข้อความคำอ้างที่ถูกตั้งคำถามเท่านั้น

### CATBOX-C05-U01-B04 · 35–45s

**VO:** “เจ้าของเลยเก็บคำว่า อ้อมกอด ไว้เป็นคำเปรียบ ส่วนแรงสัมผัสที่อาจทำให้สบาย ยังเป็นสมมติฐาน กล่องไม่ได้ถูกพิสูจน์ว่าไม่สบาย แค่เรายังยืนยันเหตุนี้ไม่ได้”

**ซับ:** “คำเปรียบ ≠ ผลทดลอง” / “แรงสัมผัสอาจมีส่วน แต่ยังไม่ยืนยัน”

**Causal handoff:** ไม่เปลี่ยนlack of evidenceเป็นหลักฐานว่าแรงกดไม่มีผล

## Long U02 — เดินมาดู กับเลือกนั่ง ต่างกันไหม? (0–45s)

### CATBOX-C05-U02-B01 · 0–10s

**VO:** “ของใหม่เรียกแมวมาดู แล้วไงต่อ? เจ้าของวางของชิ้นใหม่ โมจิเดินมาดม เขาจ่อปากกาจะเขียนว่า เพราะอยากรู้อยากเห็น แต่โมจิเดินออกไปเสียก่อน”

**ซับ:** “เดินมาดู แล้วเลือกอยู่ไหม?” / “เรื่องสมมติ: โมจิดมแล้วเดินออก”

**เหตุการณ์:** ป้าย “เรื่องสมมติ” ก่อนการดม; ปลูกCL05. ไม่บังคับพฤติกรรมให้เหมือนผลpaper

### CATBOX-C05-U02-B02 · 10–24s

**VO:** “มีงานที่ศึกษาวัตถุใหม่กับพฤติกรรมสำรวจในแมวโตยี่สิบเอ็ดตัว พบการสำรวจเมื่อมีวัตถุใหม่ ทั้งแบบเติมกลิ่นหนูและไม่เติมกลิ่นหนู แต่เขาใช้วัตถุไม้ทรงลูกบาศก์หุ้มผ้า ไม่ใช่กล่องเปิดให้ลงไปนั่ง”

**ซับ:** “งานสำรวจวัตถุใหม่ / แมวโต 21 ตัว” / “ไม้ทรงลูกบาศก์หุ้มผ้า” / “ไม่ใช่กล่องเปิดให้นั่ง”

**ข้อความภาพ:** “Machado & Genaro 2014 / ภาพอธิบายงานวิจัย”; ไม่วาดกล่องเปล่าแทนวัตถุไม้แล้วใช้จำนวน21ทับ

### CATBOX-C05-U02-B03 · 24–35s

**VO:** “ความใหม่จึงอาจอธิบายว่าทำไมเดินมาสำรวจได้บางส่วน แต่ยังไม่ใช่คำตอบครบว่าทำไมเลือกนั่งหรืออยู่นาน ถ้าเราใช้คำว่า เพราะสงสัย ตอบทั้งสองคำถาม ก็อาจข้ามหลักฐานไปอีกขั้น”

**ซับ:** “เหตุที่เดินมาสำรวจ” / “ยังไม่เท่ากับเหตุที่เลือกพัก”

### CATBOX-C05-U02-B04 · 35–45s

**VO:** “เจ้าของมองแฟ้มที่แยกไว้ แล้วเพิ่งเห็นปัญหา เขาไม่ได้ขาดคำตอบอย่างเดียว เขาเอาคำตอบของคนละคำถามมาปนกัน ได้เวลาจัดแฟ้มคดีใหม่แล้ว”

**ซับ:** “คำตอบของคนละคำถาม” / “ได้เวลาจัดแฟ้มใหม่”

**เหตุการณ์:** กล่องเก่ายังอยู่มุมเดิม ไม่ให้โมจิเลือกพักจนC06เพื่อเก็บpayoff

## Short S01 — กล่องเหมือนอ้อมกอด พิสูจน์แล้วไหม? (45s)

### CATBOX-C05-S01-B01 · 0–8s

**VO:** “กล่องเหมือนอ้อมกอด พิสูจน์แล้วไหม? คำอธิบายนี้น่ารัก แต่ยังไม่ควรพูดว่าแมวจำอ้อมกอดแม่ได้”

**ซับ:** “กล่องเหมือนอ้อมกอด?” / “ยังไม่ใช่เหตุที่พิสูจน์แล้ว”

### CATBOX-C05-S01-B02 · 8–22s

**VO:** “มีผู้เชี่ยวชาญเสนอว่า สัมผัสด้านข้างอาจทำให้สบาย แต่ในหลักฐานที่ตรวจรอบนี้ ยังไม่พบการทดลองแมวที่แยกแรงกดจากการซ่อนและอุณหภูมิ เพื่อยืนยันเหตุของการเลือกกล่อง”

**ซับ:** “สัมผัสด้านข้างอาจมีส่วน” / “ยังไม่พบการแยกทดลองแรงกดในชุดนี้”

### CATBOX-C05-S01-B03 · 22–34s

**VO:** “งานที่พบว่าที่ซ่อนช่วยการปรับตัว ก็ไม่ได้พิสูจน์กลไกแรงกด ส่วนเรื่องจำอ้อมกอดแม่ เรายังไม่มีหลักฐานยืนยันในชุดนี้ อย่าเอาคำเปรียบไปแทนผลทดลอง”

**ซับ:** “ผลของที่ซ่อน ไม่ได้ยืนยันแรงกด” / “เรื่องจำอ้อมกอดแม่: ยังไม่ยืนยัน”

### CATBOX-C05-S01-B04 · 34–45s

**VO:** “พูดได้ว่า อาจเป็นหนึ่งเหตุ ไม่ใช่เฉลยที่ยืนยันแล้ว คำตอบที่น่ากอด ก็ยังต้องผ่านหลักฐานเหมือนกัน”

**ซับ:** “น่ากอด ก็ยังต้องมีหลักฐาน”

**ท้าย:** เสียงจบเป้าราว42s ค้าง3s; คำ “สมมติฐาน” อยู่ตั้งแต่B01ไม่รอท้าย; ไม่เพิ่มลูกแมวในภาพประกอบ
