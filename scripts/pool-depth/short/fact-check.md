## 2. Answers to Preaw's open questions

1. **B04 subtitle "≈ ¾".** Acceptable. In R1 the condition is on the **same** subtitle line ("มองตรงลงมา: เห็น ≈ ¾ ของความลึกจริง"), not only on the previous line, so the figure never appears without it. Keep that line as one caption unit; if Editor splits it, the condition must stay visible on screen with the ¾ and with "ลึก 2 ม. ดูราว 1.5 ม.". Keep the Film/Mark note forbidding ¾ on the oblique child-at-the-edge view.
2. **B02 "ตาเรามักคิดว่าแสงเดินเป็นเส้นตรง".** Physically sound (F001: the eye/brain places the image along the straight-line back-extension of the arriving ray), but "มัก" ("tends to") wrongly implies sometimes not, and "ตา...คิด" is loose. Prefer the "brain/interprets" form without "มัก", for example "สมองเราตีความว่าแสงเดินเป็นเส้นตรงเสมอ". This is a precision fix, not a different claim; it stays light-path physics, not "ตาโกหก". Either form is acceptable if Preaw keeps "ภาพของก้นสระถูกยกให้สูงขึ้น".
3. **"ลงเท้าก่อนในครั้งแรก".** Faithful to SRC004's English ("feet first the first time") but ambiguous in Thai: it can be read as "first time in your life". Fix: "ลงน้ำที่ไม่คุ้นครั้งแรก ให้ลงเท้าก่อน" or "ครั้งแรกที่ลงน้ำ ให้ลงเท้าก่อนเสมอ". Note the source itself does not define "first" (see SRC004 row); the "unfamiliar water" gloss is Boat's reading, so the shorter "ครั้งแรกที่ลงน้ำ ให้ลงเท้าก่อน" is the safest wording.
4. **95% figure.** Keep omitting. If added, it must read as reported guidance, for example "รายงานจากองค์กร Parachute ของแคนาดา: การบาดเจ็บจากการดำน้ำเกือบทั้งหมด (95%) เกิดในน้ำลึกไม่เกิน 1.5 ม." Limits: Canada, single organizational page, underlying study unopened (F007), and the number shows shallow-water diving is dangerous, not that refraction caused it. It adds nothing the B05 advice needs.
5. **B03 coin demo source.** Found an openly checkable procedure source (SRC012, NZCER). Wording need not be softened to "ตัวอย่างการทดลอง" but needs the small fixes in the table (image rises, do not move, keep the head still). The opaque container is a physical requirement of the "rim hides the coin" setup, supported by logic and SRC001, not by SRC012 literally.
