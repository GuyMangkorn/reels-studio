# Context map: episodes

> One entry per episode: its script folder, compositions, painted source and tests. Part of the [context map](context-map.md); shared topics live there. Checked by `scripts/context-map.py` together with it.

**Use:** `grep -n '^## ' docs/context-map-episodes.md | cut -c1-80` lists episodes; `sed -n '/^## EDU-EP26/,/^## /p' docs/context-map-episodes.md` prints one entry. Do not read the whole file.

**Keep it current:** a new episode gets its own `## <ID>` heading; a new file for an episode goes on a bullet under that heading, in the same commit.

**Read when:** working on one episode. Script folder holds research, script, delivery record, scene sheets and build notes; `src/videos/<episode>/index.ts` registers its compositions.

Painted plate and sheet IDs (`S02-SH01`, `KSO-LF01`, `ZCPAINT-R26-A`, …) are listed by the episode's `src/painted/shots/<episode>.tsx` and [spike/index.ts](../src/painted/spike/index.ts).
