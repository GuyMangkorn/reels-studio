On 2026-10-29 the user reviewed char_base body lineups and set the visual direction:
- Body proportions are near-realistic (~7–7.5 heads tall). The reference body is the "elder" lineup body (adult canon, height 1.68, stoop 0.5). This covers body proportions only; head/face style is decided separately (clay head work).
- Hands are cartoon mittens: one tapered mass plus a thumb lump, no separate fingers.
- The neck is slim and tapered, not a thick column.
- The armpit join is tight, and the shoulders must not bump when the arm is raised.
- The torso surface is smooth, with no lumps or seams.
- Female bodies need clear cues (waist, hips, bust); the user flagged the sex=1 bodies as reading strange.

**Why:** The user found the early lineup bodies (sex 1, heavy+stylized, heads_tall 3.5) "very strange". Only the elder body read as well-proportioned.

**How to apply:** Judge char_base body and outfit work against this. Show the user before/after renders of the visual changes. Proposed changes to docs/character-proportion-principles.md go to the user for review first.
